# Compatibility

The qualified integration targets Samsung S90C, Tizen 9, ARMv7 and .NET 6.
Bootstrap checks pin the firmware/framework environment; a matching product
family or marketing version alone does not establish support.

Private APIs, HDMI identifiers, native application identity and package security
labels are platform-specific. `com.samsung.tv.bixby-promotion` and the
`BixbyPromotion` assembly names are carrier requirements, not product branding.
Keep that package installed while it hosts Cove.

Matching framework assemblies must be supplied locally for native compilation.
No firmware image, bootloader replacement, general root installer or hardware
recovery method is provided. Adapting another model requires fresh inventory,
compatibility checks, backups and a scoped recovery plan.

Browser previews demonstrate layout and interactions, not compositor behavior.
Native fonts come from the TV. Future firmware, complete AC removal, every
console signal transition, accessibility speech and long-run memory behavior
are not comprehensively qualified. See [validation](remaining-validation.md).
